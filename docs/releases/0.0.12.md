# Unified VPN 0.0.12, Build 2026090802

Alpha release. Please read the known limitations before updating.

## Highlights

- Android and Windows download updates inside the app with progress, HTTPS,
  size limits and mandatory SHA-256 verification. The verified local file opens
  in the system installer; installation confirmation is still required.
- Windows installers have a build-specific ProductCode and retain the existing
  upgrade family, including replacement of earlier builds of the same version.
- Android notification opens a compact, scrollable profile chooser with status,
  duration and available traffic counters. Previous, Stop and Next actions are
  protected against locked-device access and overlapping connection requests.
- Explicit System/English/Russian language and System/Light/Dark theme choices;
  monochrome styling, visible drag feedback and scrollable connection forms.
- Hardened profile-switch lifecycle, sensitive-screen protection, diagnostic
  redaction and native asset/provenance checks.
- Encrypted friend packages contain ready client profiles, never SSH login
  credentials. The creator provisions a separate AWG peer; the recipient only
  decrypts and imports. This is not an account-based invitation service.

## Checks

- Android API 35 emulator: olcRTC and AWG reached Connected and passed real
  VPN-bound HTTPS with certificate validation and response-body reads; active
  profile switching did not crash the app. Original app data were restored.
- Windows: olcRTC, VLESS and AWG passed authenticated local SOCKS, external HTTPS
  and clean Stop. Host VPN, proxy, DNS and routes were not changed.
- JVM suite: 169 ordinary cases passed; the three opt-in live cases also passed
  in a separate configured run. Four focused downloader regressions passed.
- Release APK signature/native audit, Windows EXE/ZIP payload audit, actual
  packaged JVM launch and compiled MSI upgrade-policy checks passed.
- Personal profiles, server addresses, keys and credentials are not release
  assets. The original Android signing certificate is retained for updates.

## Known Limitations

- **Windows TUN is temporarily unavailable.** Local SOCKS and System proxy
  remain available. Elevating the entire GUI/native runtime is refused until
  a narrowly scoped privileged helper is implemented.
- **Android VLESS had intermittent startup DNS/TLS failures.** Later HTTPS
  probes succeeded on the same connections without changed settings, but the
  initial failures remain unexplained. This is not a clean stability pass.
- Connected can describe local engine/TUN readiness, not proof of successful
  external DNS or HTTPS. Real traffic was checked separately.
- Physical Android devices and installation over the owner's working Windows
  copy were not exercised by these automated tests. Windows Authenticode signing
  is not configured. The APK is non-debuggable and uses the existing compatible
  locally held signing key.
- The pinned olcRTC SOCKS engine supports TCP, not general UDP. Android DNS is
  bridged over TCP. Older incompatible olcRTC servers are not upgraded by this
  client release; no server configuration was changed.

## Files

- Android: `UnifiedVPN-0.0.12-build.2026090802-android-universal.apk`
- Windows: `UnifiedVPN-0.0.12-build.2026090802-windows-amd64-installer.exe`
- Verification: `SHA256SUMS.txt`

The Windows EXE is used for installation and updating. A portable ZIP is not
attached: older clients prefer ZIP assets, which would select the old update
path instead of the installer. Existing releases are kept for manual rollback;
Android does not normally allow installing a lower versionCode over a newer one.

Unified VPN is based on the original [olcbox by Alan Anisimov](https://github.com/alananisimov/olcbox).
The original project attribution is retained. New account-based onboarding and
adaptive protocol selection are separate 0.1.x design work, not features of
this release.

# Unified VPN 0.0.12, Сборка 2026090802

Альфа-версия. Перед обновлением прочитайте известные ограничения.

## Основные Изменения

- Android и Windows скачивают обновление внутри приложения с прогрессом,
  проверкой HTTPS, размера и обязательного SHA-256. Проверенный локальный файл
  открывается системным установщиком; подтверждение установки остаётся.
- Windows-установщик получает отдельный ProductCode на каждый build и сохраняет
  семейство обновлений, включая замену прежних сборок с тем же номером версии.
- Нажатие на Android-уведомление открывает компактный прокручиваемый список
  профилей со статусом, длительностью и доступной статистикой трафика. Действия
  «Предыдущий», «Стоп», «Следующий» защищены от управления на заблокированном
  устройстве и пересечения запросов подключения.
- Явный выбор системного/английского/русского языка и системной/светлой/тёмной
  темы, монохромное оформление, видимое перетаскивание и прокрутка настроек.
- Усилены переключение профилей, защита чувствительных экранов, очистка логов
  и проверки происхождения и состава native-библиотек.
- Зашифрованные пакеты для друзей содержат готовые клиентские профили, но не
  SSH-данные входа. Создатель выдаёт отдельный AWG peer, получатель только
  расшифровывает и импортирует пакет. Это ещё не сервис персональных аккаунтов.

## Проверки

- Android-эмулятор API 35: olcRTC и AWG дошли до Connected и передали реальный
  HTTPS-трафик через VPN с проверкой сертификатов и чтением тела ответа.
  Переключение активных профилей не вызвало вылета; исходные данные восстановлены.
- Windows: olcRTC, VLESS и AWG прошли проверку SOCKS-аутентификации, внешнего
  HTTPS и остановки. VPN, прокси, DNS и маршруты владельца не изменялись.
- Успешны 169 обычных JVM-проверок и отдельный запуск трёх интеграционных тестов
  с приватными профилями. Четыре регрессионных теста загрузчика также прошли.
- Проверены подпись и native-состав APK, содержимое EXE/ZIP, фактический запуск
  упакованной JVM и правила обновления скомпилированного MSI.
- Приватные профили, адреса серверов, ключи и пароли не входят в релизные файлы.
  Исходный Android-сертификат сохранён для совместимости обновлений.

## Известные Ограничения

- **Windows TUN временно недоступен.** Локальный SOCKS и системный прокси
  доступны. Повышение прав всего GUI/native runtime запрещено до появления
  отдельного минимального привилегированного helper.
- **При запуске Android VLESS наблюдались ошибки DNS/TLS.** Позднее HTTPS
  заработал на тех же соединениях без изменения настроек, но причина первых
  ошибок не установлена. Это не чистый проход проверки стабильности.
- Connected может означать готовность локального движка/TUN, но не подтверждает
  работоспособность внешнего DNS и HTTPS. Реальный трафик проверялся отдельно.
- Автотесты не выполняли проверку физического телефона и установку поверх
  рабочей Windows-копии владельца. Authenticode-подпись EXE не настроена. APK
  неотладочный и подписан прежним совместимым ключом, хранящимся локально.
- Закреплённый olcRTC SOCKS поддерживает TCP, но не произвольный UDP; DNS Android
  передаётся через TCP. Несовместимые старые olcRTC-серверы этим выпуском клиента
  не обновляются. Серверные настройки не менялись.

## Файлы

- Android: `UnifiedVPN-0.0.12-build.2026090802-android-universal.apk`
- Windows: `UnifiedVPN-0.0.12-build.2026090802-windows-amd64-installer.exe`
- Контрольные суммы: `SHA256SUMS.txt`

Windows EXE используется и для установки, и для обновления. Portable ZIP не
прикреплён: старые клиенты предпочитают ZIP и иначе выберут прежний путь
обновления вместо установщика. Старые выпуски сохранены для ручного возврата;
Android обычно не позволяет установить меньший versionCode поверх нового.

Unified VPN основан на оригинальном [olcbox Алана Анисимова](https://github.com/alananisimov/olcbox).
Упоминание оригинального проекта сохранено. Персональная выдача доступа и
автоматический выбор протокола проектируются отдельно для 0.1.x и в этот
выпуск не входят.
