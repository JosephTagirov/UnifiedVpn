## UnifiedVPN 0.1.16

- В Android в списках раздельного туннелирования можно показывать доступные системные приложения и выбирать их по отдельности.
- В Windows режим **TUN (VPN)** поддерживает профили VLESS и AmneziaWG с несколькими адресами входа. При запуске маршруты к этим адресам проходят через физический интерфейс, чтобы VPN мог работать с основным и резервным входом.

Для Windows откройте **Настройки → Подключение → TUN (VPN)**. Windows запросит разрешение на запуск сетевого помощника. VK Calls, другие профили olcRTC и OpenFlux на Windows используют доступные прокси-режимы.
