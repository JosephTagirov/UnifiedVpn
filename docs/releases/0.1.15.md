## UnifiedVPN 0.1.15

- При обновлении подписки сохраняются ручной порядок и выбранный профиль. Если профиль исчез из подписки, приложение сообщает об этом.
- Android проверяет сроки обновления подписок через системное фоновое задание.
- Режим «Авто по скорости» сравнивает загрузку через профили и переключается после двух замеров с заметным преимуществом. Доступен в Android и в прокси-режимах Windows.
- Исправлен запуск AdBlock. Если фильтр временно недоступен, приложение сохраняет VPN-соединение и показывает предупреждение.
- Яндекс Интернетометр и его серверы измерения включены в правила прямого маршрута. Speedtest использует VPN.

На Android устанавливайте APK поверх предыдущего выпуска. В Windows используйте установщик EXE для обновления установленного приложения или ZIP для переносной версии.
