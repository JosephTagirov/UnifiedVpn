# UnifiedVPN 0.1.5 / 2026110204: объединённая сборка

По запросу пользователя Android и Windows собраны из одного набора исходников,
содержащего адблокер, обновлённый OpenFlux и ручное обновление подписки.
Версия осталась 0.1.5; номер сборки и Android versionCode увеличены до 2026110204,
чтобы отличать объединённые файлы от прежних вариантов 2026110203.

Сохранены проверка внешнего VPN, автоматический выбор прокси, AWG/VLESS TUN
и исправления XHTTP. Обычная пользовательская редакция: Android OWNER_EDITION=false,
в Windows отсутствует параметр ownerCabinet. Серверные службы и сетевые настройки
компьютера не менялись. Установщик на компьютер пользователя не запускался.

## Проверки

- Полная Gradle-сборка завершилась успешно: 500 JVM-тестов, 352 Android host-теста,
  без ошибок и пропусков. Реальный тест фильтра sing-box запущен с явным
  UNIFIEDVPN_SING_BOX_TEST_BINARY; проверены блокировка доменов, DNS NXDOMAIN,
  передача разрешённого трафика и остановка.
- В APK DEX и Windows JAR присутствуют все три набора функций. Список HaGeZi
  Multi LIGHT одинаковый в обоих пакетах, SHA-256
  `6c62f367faf262b65561199a2e654f34bf491d63ac9c03b1c91d36d86706ba50`;
  NOTICE и лицензия включены. Классические OpenFlux-бинарники для Windows
  и трёх Android ABI совпадают с проверенными артефактами нового overlay.
- APK проверен apksigner, v1/v2 корректны; сертификат совпадает с сохранённой
  сборкой с адблокером 2026110203. Application ID `app.unifiedvpn.local`,
  versionCode 2026110204; debuggable отсутствует.
- CRC APK и portable ZIP корректны. Все 273 файла ZIP совпадают с образом
  приложения, прошедшим запуск JVM и проверку встроенных ядер.
- EXE прошёл проверку версии/номера сборки, обновления в пределах одной версии,
  безопасного порядка замены, запрета установки поверх запущенного UnifiedVPN
  и ожидания перезагрузки. Все 31 тест политики установщика также прошли.
- Живой тест использовал именно классы из JAR итогового Windows-образа;
  загруженный номер сборки проверен до запуска. Через приватный VLESS/XHTTP-профиль
  и локальный SOCKS с включённым по умолчанию адблокером прошёл проверенный HTTPS
  к двум сайтам и остановка за 4,899 с. Секреты и диагностические журналы
  сохранены только в защищённом локальном каталоге.
- Второй тест итогового Windows-образа получил конкретную ошибку просмотра
  вместо редактора OpenFlux, не получил ложный Ready, подтвердил остановку
  процесса, закрытие SOCKS и удаление временного конфига за 2,091 с.

## Файлы и ограничения

APK, EXE, portable ZIP, SHA256.json и отчёты сохранены в
`dist/UnifiedVPN-0.1.5-build.2026110204/`. Пользовательские пакеты и исходники
подготовлены для [релиза v0.1.5](https://github.com/JosephTagirov/UnifiedVpn/releases/tag/v0.1.5).
Журнал: `build/combined-final-2026110204.log`; проверка состава:
`build/verify-combined-2026110204.py`.

Нестабильная проверка Яндекса остаётся известным ограничением OpenFlux.
Однократный успех получения конфигурации старого редактора не подтверждает
устойчивый туннель. Новые документы/Volga и итоговый APK на физическом Android
ещё не прошли полную живую проверку. История диагностики приведена в
[отчёте OpenFlux](openflux-editor-diagnostics-20260929.md).
