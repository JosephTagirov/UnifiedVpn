# VK Calls Local Build 2026101301

## English

Version: Unified VPN 0.0.14 build 2026101301. This report records local validation
before publication; no GitHub change was part of the connection tests. See the
[release notes](../releases/0.0.14-build.2026101301.md) for public artifacts.

### Integration

VK Calls is an olcRTC provider using a separate unmodified native fork at
`403edd409011dd371796260196ecd17630df0fdd`, VP8 60 FPS/batch 64 and DTLS
`chrome-linux-138-compat-v1`. The Jitsi core remains
`d7a00da5242f72a48b505ffc4b6aa8246376bf25`. All three packaged Android Jitsi
libraries are byte-identical to the preceding 2026101102 APK.

Android starts a separate PIE executable under the application UID, not a second
gomobile library. It uses the existing external-engine lifecycle, authenticated
loopback SOCKS and olcRTC split-tunneling group. Readiness, cancellation, Stop,
bounded startup retries, TLS failure behavior and secret redaction are covered
by tests. Windows loads a separate bundled binary and retains its existing
olcRTC proxy-mode and startup-retry paths.

The private VK share link round-trips through the actual repository import/export
API without losing its provider, room, key or VP8 settings. Neither it nor its
room/key is included in public artifacts or this report.

A separate permanent `unifiedvpn-vkcalls-01.service` is enabled. It uses
DynamicUser, LoadCredential, a root-only 0600 configuration, a 384 MiB memory
cap and a read-only system filesystem. No listening host port, firewall change,
NIC change or restart of existing Jitsi/AWG/OpenFlux/Xray services was needed.
The new service was observed active with zero automatic restarts after traffic
checks. Rollback affects only this new service:

```bash
sudo systemctl disable --now unifiedvpn-vkcalls-01.service
```

### Limits

- Tests used the laptop's existing external AmneziaVPN. They do not establish direct operation during Megafon whitelist restrictions.
- Physical Android 13, sustained application throughput, a long soak, multiple simultaneous clients and Windows installation over the user's current application have not been tested.
- Earlier native Windows measurements of roughly 12-19 Mbps and emulator measurements of roughly 1-3 Mbps used different conditions. They are not speed guarantees for these final application artifacts.
- Windows VK TUN and Android inactive-profile latency probing are not implemented. Existing Jitsi binaries/AAR were preserved and regression-tested structurally, not live-tested with FI_2/FI_3 in this session.
- Final publication preparation collected native dependency notices for 226 versions, retained upstream attribution and supplied corresponding source archives. The source/artifact privacy scan and all 18 updater tests passed. This does not replace physical-device user acceptance or the unperformed tests above.

### Интеграция

VK Calls добавлен как провайдер olcRTC через отдельный неизменённый форк
`403edd409011dd371796260196ecd17630df0fdd`, VP8 60 FPS/batch 64 и DTLS
`chrome-linux-138-compat-v1`. Jitsi сохраняет ядро
`d7a00da5242f72a48b505ffc4b6aa8246376bf25`. Три Android-библиотеки Jitsi
побайтно совпадают с APK 2026101102.

Android запускает отдельный PIE-процесс под UID приложения, а не второе
gomobile-ядро. Используются существующие механизмы внешних ядер, SOCKS
с авторизацией и группа раздельного туннелирования olcRTC. Тесты покрывают
готовность, отмену, остановку, ограниченные повторы, ошибки TLS и скрытие
секретов. В Windows используется отдельное встроенное ядро и существующие
прокси-режимы и повторные попытки olcRTC.

### Ограничения

- Проверки проводились через уже работающую внешнюю AmneziaVPN ноутбука. Прямое подключение при белых списках Мегафона этим не подтверждено.
- Не проверены физический Android 13, длительная скорость приложения, продолжительный сеанс, несколько одновременных клиентов и установка Windows поверх текущей пользовательской версии.
- Прежние замеры отдельного ядра около 12-19 Мбит/с на Windows и 1-3 Мбит/с в эмуляторе проводились в других условиях. Это не гарантия скорости итоговых APK/MSI.
- Windows TUN для VK и пинг неактивного VK-профиля на Android не реализованы. Прежние ядра/AAR Jitsi сохранены и проверены структурно, но FI_2/FI_3 в этой сессии не проверялись живым подключением.
- При подготовке публикации собраны уведомления для 226 версий зависимостей, сохранена upstream-атрибуция и приложены соответствующие исходники. Пройдены проверка приватных данных и все 18 тестов апдейтера. Это не заменяет приёмку на физическом устройстве и непроведённые проверки выше.
