# Проверка UnifiedVPN 0.1.6 / 2026110301

Редакция владельца собирается из того же исходного кода с номером 2026110302.
Ключи, приватные профили и ссылки на комнаты не включаются в репозиторий.
Общие проверки: 506 JVM-тестов и 354 Android host-теста, без ошибок и пропусков.

## VLESS/XHTTP

- Общий генератор Xray используется Android и Windows. Официальное ядро Xray
  26.10.31 проверяет конфигурации транспортов, включая XHTTP `extra` и отдельный
  download endpoint. Для Android сохраняется его политика bootstrap DNS.
- Приватный серверный профиль проверен живыми HTTPS-запросами через loopback SOCKS:
  политика Windows и политика Android, каждая с адблоком и без него. Все четыре
  варианта получили HTTP-ответы от Wikipedia, Instagram и Telegram; рекламный
  домен при включённом фильтре отклонён. Порты освобождены после остановки.
- Проверка запрашивает HEAD: полная страница Instagram может долго передавать
  потоковый ответ. Первоначальный тайм-аут после HTTP 200 и сотен килобайт данных
  не был доказательством неисправности XHTTP.
- Тест Android-политики выполняется Windows-ядром с Android-конфигурацией;
  он не заменяет проверку VpnService на физическом Android-устройстве.
- Готовые JAR из Windows-пакета 2026110301 отдельно прошли реальное подключение
  VLESS/XHTTP и проверку понятной ошибки OpenFlux для ссылки на просмотр файла
  с последующей остановкой. Это не подмена упакованного кода классами IDE.

## OpenFlux

- Classic wrapper 9 и Session wrapper 4 собраны для Windows, Linux и трёх Android ABI.
  Пройден выбранный набор upstream Go-тестов и новые проверки отмены.
- 14 запусков Windows-ядер во время ожидания bootstrap/соединения завершились
  после STOP или EOF за 6–44 мс: classic, Volga и Session. Watchdog ограничивает
  зависшую очистку ядра 1,5 секунды после отмены.
- Проверены отмена ожидающего dial и остановка Windows-клиента во время
  незавершённой предварительной проверки. Очистка VPN выполняется после отмены.
- Стабильный живой туннель через защищённый проверкой редактор Яндекса не
  подтверждён. Исправление остановки не снимает эту отдельную проблему доступности.

## Установка Windows

- Проверены 31 отрицательный/положительный сценарий политики MSI и 10 сценариев
  выбора установки, обновления, восстановления и запрета понижения версии.
- Отдельный небольшой MSI с уникальной тестовой семьёй прошёл настоящие транзакции:
  установка, обновление 0.1.5 → 0.1.6, замена другой сборки 0.1.6 и восстановление
  точно той же сборки. Все коды завершения — 0; тестовый пакет удалён.
  Производственная семья UnifiedVPN не изменялась.
- Скрытое тестовое приложение в зарегистрированном каталоге получило обычное
  закрытие и завершило обработчик очистки. Одноимённый процесс из другого каталога
  остался работать. Занятый файл отклонён до начала установки; повреждённый MSI
  отклонён по SHA-256. Полная установка пользовательской копии не выполнялась.
- Внешний вид окна проверен по отрисованному изображению; подпись Android APK
  сверяется с прежней опубликованной версией для сохранения возможности обновления.

## Адблок и обновления

Адблок выполняется локальным sing-box с HaGeZi Multi LIGHT; механизм и ограничения
описаны в [AD_BLOCKING.md](../AD_BLOCKING.md). На проверенном сервере отдельный
рекламный DNS-фильтр отсутствует. Обновление подписки меняет профили, список рекламы
доставляется с приложением.

Редакция владельца использует отдельный `/vpn-control/updates/owner.json` и
отклоняет публичную сборку вместо молчаливой потери функций владельца. Для
публичной редакции сохраняются сервер и GitHub как источники одного файла.
